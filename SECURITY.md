# Безопасность

Исправления в первую очередь выпускаются для последней публичной версии.

Не публикуйте в открытых issue пароли, токены и конфиденциальные DXF. Для обычной ошибки используйте минимальный демонстрационный файл. Для уязвимости с чувствительными подробностями свяжитесь с владельцем через доступные контакты его [профиля GitHub](https://github.com/BrianIS8090) и согласуйте закрытый канал передачи.

Приложение читает локальные DXF и не загружает их на сервер. Это не делает любой входной файл безопасным: повреждённые или очень большие файлы могут вызвать повышенное потребление ресурсов. Проверку перед производством необходимо выполнять отдельно.

Официальные исполняемые файлы публикуются только в [Releases](https://github.com/BrianIS8090/dxf-canvas/releases). Цифровой подписи пока нет; сверяйте SHA-256 скачанного файла с `SHA256SUMS.txt` соответствующего выпуска.
