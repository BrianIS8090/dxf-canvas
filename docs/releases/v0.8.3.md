# DXF Холст 0.8.3

## Исправления

- Переключение «Деталь с отверстиями» / «Отдельный контур» сохраняет активный инструмент площади. Раньше кнопка вызывала общую отмену, которая при отсутствии незавершённого размера включала инструмент выбора.
- Готовый замкнутый объект на плане измеряется отдельно от окружающих линий. Раньше после нахождения границы продолжался обход посторонних цепочек, исчерпывавший защитный лимит на шестиугольниках большого эталона.
- Из вложенных замкнутых объектов выбирается меньший под курсором. Если готового замкнутого объекта нет, поддержан поиск цепочки отдельных линий/дуг с ограничением сложности.

## Использование

Нажмите **Площадь / периметр → Отдельный контур**, затем внутри элемента. Проверьте подсвеченную границу и разместите подпись вторым щелчком. S отображается в м², P — в м. В этом режиме отверстия не вычитаются, прорези не добавляются. Для детали с отверстиями и разгрузочными прорезями предусмотрен отдельный режим.

Это измерение геометрического объекта, не распознавание комнат из произвольной сети стен. Неподдерживаемые объекты не восстанавливаются автоматически. Скрытые слои, тексты и штриховки не участвуют в расчёте режущих контуров. Самопересечения выбранной границы остаются причиной отказа.

## Проверки

- Автоматические нажатия обеих кнопок через настоящий интерфейс egui.
- Замкнутый объект с 33 посторонними открытыми линиями: граница измеряется независимо.
- 20 контрольных шестиугольников частного DXF: независимая проверка площади и периметра по геометрии правильного шестиугольника с учётом вложенных объектов.
- Проверки тяжёлой диагностики, окружности на плане и ранее исправленной детали с прорезями.

Производственный чертёж не включается в репозиторий. Локальные проверки:

```powershell
$env:DXF_HEAVY_FIXTURE = 'C:\путь\эталон.dxf'
cargo test --locked --release heavy_reference -- --ignored --nocapture
```

Включены предыдущие изменения 0.8.2: фоновая проверка со спиннером, ограниченная нагрузка диагностической подсветки без удаления замечаний из списка и вывод S/P в м²/м.
