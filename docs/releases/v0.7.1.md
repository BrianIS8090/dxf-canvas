# DXF Холст 0.7.1

Исправлено отображение кириллицы в старых DXF и в DWG, преобразуемых во временный DXF. Искажались названия слоёв, текстовые объекты и имена блоков: кодировка Windows-1251 ошибочно читалась как Windows-1252.

Теперь оба обработчика DXF используют кодировку из заголовка файла. Регистр `ansi_1251` не влияет на результат; современные UTF-8 чертежи и западноевропейские Windows-1252 проверены отдельно.

Проверка на частном DWG версии AC1018 с 84 слоями проходит. Производственный файл не включён в выпуск. После обновления откройте исходный DWG заново; править или пересохранять его не нужно.

## Файлы

- `DXF-Canvas-0.7.1-windows-x64.exe` — автономная программа Windows x64.
- `SHA256SUMS.txt` — контрольная сумма EXE.
- `THIRD-PARTY-LICENSES.txt` — уведомления о сторонних компонентах, также встроенные в EXE.
