# DXF Холст 0.9.9 — сложные DWG, области и штриховки

Исправлено открытие сложных DWG, которое прерывалось при чтении MULTILEADER. Конвертер обновлён до ACadSharp 3.8.35. Исходные чертежи остаются без изменений.

## Что изменилось

- Стены, таблицы, выноски и пользовательские объекты с поддерживаемой сохранённой графикой преобразуются в линии, дуги, текст и заливки. Для каждого исходного объекта выбирается одна графическая замена.
- Восстанавливаются MLINE и аналитические плоские REGION в формате SAB 22300: отрезки, точные эллиптические дуги и внутренние контуры. Проверяются связи, замыкание и покрытие рёбер; неподдержанные данные не пропускаются молча.
- После записи временный DXF читается повторно. Сверяются состав объектов, их идентификаторы и порядок наложения; двойные замены отклоняются.
- Маски WIPEOUT учитывают слои, вложенные блоки, преобразования и порядок отрисовки в обеих темах.
- Плотные HATCH сохраняются компактно. При увеличении рисуется видимый участок исходного рисунка; при недостаточном масштабе используется явно обозначенное обзорное представление с отверстиями. Число операций на кадр ограничено.
- Исправлены пропуски штриховки из-за нулевой двухточечной границы, отражённые и наклонные эллипсы, некорректные экранные координаты при сильном отдалении.
- Восстанавливаются конфликтующие ключи стилей MLINE и корректные имена цветов RAL.

## Проверки и ограничения

Локально прошли **225 Rust-тестов**, форматирование, Clippy и шесть наборов проверок конвертера. Все пять частных DWG прошли нативное преобразование, повторное чтение, загрузку в просмотрщик и построение кадра. Исходные файлы побайтно не изменились. В вентиляционном эталоне восстановлены **812 REGION и 38 052 аналитических ребра**; сохранены также 12 плотных штриховок. Рабочие чертежи в репозиторий и релиз не включены.

Успешная проверка состава не означает полного визуального совпадения с CAD. В эталонах остаются две внешние PDF-подложки без предоставленного PDF, одно неподдерживаемое 3D-тело и виды на листах VIEWPORT. Нестандартные шрифты, включая SHX, могут заменяться. Некоторые свойства сохранённой графики требуют сверки с авторской CAD; предупреждения доступны в карточке импорта. Подробности и количества приведены в [матрице поддержки DWG](https://github.com/BrianIS8090/dxf-canvas/blob/v0.9.9/docs/DWG_SUPPORT.md).

## Файлы выпуска

- **DXF-Canvas-0.9.9-setup-x64.exe** — установщик для текущего пользователя Windows x64; подходит для обновления установленной версии.
- **DXF-Canvas-0.9.9-windows-x64.exe** — переносимое приложение без установки.
- **SHA256SUMS.txt** — контрольные суммы файлов.
- **THIRD-PARTY-LICENSES.txt** — лицензии компонентов.
- **SIGNING.json** — сведения о цифровой подписи; выпуск не подписан.

CAD-система, Rust, Python и .NET для запуска не нужны. Перед установкой закройте рабочие окна DXF Холст: текущая раскладка и измерения хранятся в памяти.
