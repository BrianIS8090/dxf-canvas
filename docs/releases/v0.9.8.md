# DXF Холст 0.9.8 — проверка уровней Z

Добавлена проверка высот объектов в DXF и DWG после внутреннего преобразования. Исходные чертежи остаются без изменений.

## Что нового

- В разделе **Проверка** появилась сводка **Уровни Z**: высоты и количество объектов на каждом уровне.
- Общий уровень, в том числе ненулевой, считается нормальным. Допуск — **0,01 мм**; при неизвестных единицах — 0,01 ед. DXF.
- Объекты вне уровня большинства подсвечиваются ярко-синим. В замечании указаны тип, идентификатор DXF, слой, координата Z и подписанное отклонение **ΔZ**.
- Щелчок по замечанию приближает и выделяет соответствующий объект; доступны фильтр категории и переходы **Назад / Далее**.
- Наклонные объекты показывают диапазон высот. Вложенные блоки учитываются с базовой точкой, переносом, масштабом по Z, поворотом, нормалью и массивами.
- Основной уровень должен содержать **больше половины видимых объектов файла**. Если такого большинства нет, программа сообщает об этом и перечисляет уровни без произвольного эталона.

## Границы проверки

Файлы проверяются независимо; скрытые слои не участвуют. Одна штриховка считается одним объектом. У текста сравнивается точка размещения, графика размеров исключена. Для сплайнов диапазон оценочный — по контрольным/опорным точкам; для наклонных штриховок — по точкам границы. Проверяются кривые и поверхности, не объёмы, заданные толщиной. Неподдерживаемые сущности не объявляются проверенными. Несколько уровней могут быть предусмотрены проектом: это предупреждение, а не автоматическое исправление.

Демонстрационный файл `examples/elevation_demo.dxf`: четыре окружности на Z=10 мм и две на Z=25 и Z=−2 мм. Ожидаются два замечания: +15 и −12 мм.

## Проверки

Локально прошли **202 теста**, проверка форматирования и Clippy без предупреждений. Ещё 9 тестов пропускаются в обычном запуске: им нужны частные файлы или отдельная сетевая проверка. Новые тесты охватывают единицы, допуск, большинство и его отсутствие, скрытые слои, вложенные блоки, наклонные кривые, полилинии, штриховки, текст и 50 тысяч объектов. Устранено пересечение временных файлов параллельных тестов измерений.

Подсветка, сводка и фокусировка проверены вручную на тестовой сборке. Производственные чертежи не публикуются.

## Скачать

- **DXF-Canvas-0.9.8-setup-x64.exe** — установщик для текущего пользователя Windows x64.
- **DXF-Canvas-0.9.8-windows-x64.exe** — переносимое приложение без установки.
- **SHA256SUMS.txt** — контрольные суммы файлов.
- **THIRD-PARTY-LICENSES.txt** — лицензии компонентов.
- **SIGNING.json** — сведения о цифровой подписи; этот выпуск не подписан.

CAD-система, Rust и .NET для запуска не нужны. Обновление установкой выполняется вручную; сохранение рабочего проекта и экспорт раскладки пока не реализованы.
