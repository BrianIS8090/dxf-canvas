# DXF Холст 0.7.0

## Новое

- DWG открывается напрямую: встроенный открытый конвертер автоматически создаёт временный DXF.
- Установка CAD-системы, .NET и подключение к интернету не требуются. Исходный чертёж не меняется.
- При загрузке видны спиннер, имя файла и этап обработки. Поддерживается очередь смешанных DWG/DXF.
- Предупреждения конвертации доступны в карточке файла; лицензии добавлены в меню версии.
- Исправлены исчезавшие из-за неверного чтения прозрачности линии и нестабильное разбиение дуг после преобразования.

Поддержка основана на ACadSharp 3.7.1 (MIT). Проверены синтетический DWG и частный большой эталон. Это не гарантия поддержки всех расширений DWG; смотрите [ограничения](../DWG_SUPPORT.md).

## Файлы

- `DXF-Canvas-0.7.0-windows-x64.exe` — автономная программа Windows x64.
- `SHA256SUMS.txt` — контрольная сумма EXE.
- `THIRD-PARTY-LICENSES.txt` — лицензии сторонних компонентов, также встроенные в EXE.

EXE не имеет цифровой подписи. Производственные файлы в поставку не включаются.
