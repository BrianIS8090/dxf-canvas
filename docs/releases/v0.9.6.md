# DXF Холст 0.9.6

## Установка в Windows

- Новый `DXF-Canvas-0.9.6-setup-x64.exe`: установка для текущего пользователя без прав администратора, ярлык в меню Пуск и необязательный ярлык на рабочем столе.
- Постоянный путь `%LOCALAPPDATA%\Programs\DXF Canvas\dxf-canvas.exe`; новые версии устанавливаются поверх предыдущих.
- DXF и DWG зарегистрированы в «Открыть с помощью» и «Приложения по умолчанию». Существующий выбор пользователя не меняется автоматически.
- Версия отображается в свойствах EXE и списке установленных программ.
- Установка и удаление просят предварительно закрыть приложение, чтобы не потерять раскладку и измерения незаметно.
- Переносимая версия сохранена: `DXF-Canvas-0.9.6-windows-x64.exe`.

## Проверка обновлений

- «Справка → Проверить обновления» или меню номера версии → «Обновления».
- Фоновая проверка при запуске не чаще раза в сутки; её можно отключить.
- Уведомление о новой стабильной версии, ссылки на установщик и описание изменений.
- Работа с чертежами продолжается при недоступном интернете. Файлы и их пути не передаются.
- Приложение не загружает и не устанавливает обновления без действия пользователя.

## Подпись Windows

Подготовлена подпись приложения, встроенного DWG-конвертера, установщика и удалителя доверенным сертификатом. **Этот выпуск пока не подписан:** сертификат издателя ещё не оформлен. `SIGNING.json` сообщает реальный статус. Предупреждение Windows при запуске возможно.

Самодельные корневые сертификаты не устанавливаются; настройки защиты Windows не меняются. Подробности подключения — [SIGNING.md](../SIGNING.md).
