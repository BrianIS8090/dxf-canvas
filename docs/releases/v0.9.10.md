# DXF Холст 0.9.10 — открытие сложных DWG

Выпуск исправляет открытие DWG с конфликтующими записями порядка отрисовки и ускоряет загрузку планов с большим количеством штриховок.

- Конвертер восстанавливает исходные ключи `ACAD_SORTENTS` и `ACAD_REFEDIT`, когда библиотека чтения DWG ошибочно присваивает обеим записям одно имя. Порядок наложения объектов сохраняется.
- Суммарное число отрезков штриховки, создаваемых до первого кадра, ограничено по всему чертежу. После достижения лимита программа строит штрихи по видимой области. На общем плане для плотного рисунка используется обзорное представление.

Локально прошли 226 тестов приложения и шесть наборов проверок конвертера. Семь частных DWG прошли загрузку и построение кадра, а оба новых плана освещения одновременно открылись в установленной версии. В этих двух файлах виды на листах (`VIEWPORT`) по-прежнему отмечаются в предупреждениях импорта. Рабочие чертежи в комплект выпуска не входят.

## Файлы для Windows x64

- **DXF-Canvas-0.9.10-setup-x64.exe** — установщик для текущего пользователя Windows, подходит для обновления предыдущей версии.
- **DXF-Canvas-0.9.10-windows-x64.exe** — переносимый EXE для запуска без установки.
- **SHA256SUMS.txt** — контрольные суммы файлов.
- **THIRD-PARTY-LICENSES.txt** и **SIGNING.json** — лицензии компонентов и сведения о подписи. Сборка не подписана.
