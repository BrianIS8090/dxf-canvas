# DXF Холст 0.9.2 — сохранение ручной раскладки

Добавление или удаление файла больше не переставляет остальные детали и не меняет текущий вид.

- Новые файлы добавляются справа от занятой области.
- Положение, угол поворота, масштаб и измерения оставшихся файлов сохраняются.
- «Разложить» в шапке запускает автоматическую раскладку по запросу пользователя.
- «Вписать всё» меняет только вид, не расположение деталей.
- При первой загрузке в пустое окно все принятые файлы один раз вписываются в вид после завершения очереди.

Исходные DWG и DXF не изменяются.
