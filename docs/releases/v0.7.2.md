# DXF Холст 0.7.2

Исправлено открытие DWG с виртуальных дисков, на которых раньше возникала ошибка Windows 1005 «Файловая система тома не распознана».

Причина: программа запрашивала физический путь тома через `canonicalize`. Подключённый виртуальный диск позволял читать файл, но не выполнял этот запрос. Теперь используется абсолютный путь без обращения к драйверу за физическим расположением.

Импорт проверен на исходном DWG с диска O:. Содержимое исходного файла не изменилось. Переподключать диск, менять его настройки или вручную переносить чертёж на локальный диск не требуется.

## Файлы

- `DXF-Canvas-0.7.2-windows-x64.exe` — автономная программа Windows x64.
- `SHA256SUMS.txt` — контрольная сумма EXE.
- `THIRD-PARTY-LICENSES.txt` — уведомления о сторонних компонентах, также встроенные в EXE.
