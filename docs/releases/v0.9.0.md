# DXF Холст 0.9.0 — рабочая область

## Что стало удобнее

- Файлы, слои и проверка разделены по вкладкам. Длинная легенда больше не вытесняет список файлов и настройки слоёв.
- Файлы можно искать по названию и приближать кнопкой или двойным щелчком. Путь доступен при наведении на имя.
- У площади сразу видна разница режимов: деталь с отверстиями или один контур на плане. Подсказка текущего шага вынесена под холст.
- Основные команды остались в шапке, дополнительные настройки собраны в меню «Холст». Размер подписей по-прежнему один для всех объектов.
- Справка F1 объясняет привязки, управление и единицы измерения. Для удаления всех измерений или очистки холста есть подтверждение.
- Проверка открывает отдельную сводку. Легенда показывает найденные категории, подробности всех проверок раскрываются отдельно.

## Без изменений

Исходные DWG/DXF не редактируются. Визуальный масштаб не влияет на измерения. Сохраняются фоновый импорт и проверка, светлый холст, слои, привязки и расчёты в м² / м.

## Следующие направления

1. Сохранение рабочего проекта: файлы, раскладка, видимость слоёв, размеры и положение вида; восстановление после перезапуска.
2. Ведомость выбранных контуров: названия, количества, площади и периметры, итоговые суммы и экспорт CSV.
3. Экспорт листа PDF/PNG с измерениями, масштабом и основной надписью.
4. Сравнение двух редакций чертежа с подсветкой добавленных, удалённых и изменённых участков.
5. Исправление найденных дефектов только через предварительный просмотр, отмену и сохранение отдельной копии.

Это направления дальнейшего развития, а не функции данного выпуска.
