# Импорт DWG с сохранённой графикой — план реализации

> For agentic workers: use superpowers:executing-plans or task-scoped parallel implementation, verify before completion.

**Goal:** Открывать пять частных DWG без незаметных потерь и повторного показа объектов.
**Architecture:** Обновить ACadSharp до 3.8.35. Обычные поддерживаемые сущности сохранять; Wall, UnknownEntity, TableEntity, MultiLeader заменять только один раз блоком из сохранённой графики. Отдельно исправить конфликт словаря, без общего подавления ошибок. Контролировать покрытие исходных handle и уникальность пути представления.
**Tech Stack:** Rust, egui, C# NativeAOT, ACadSharp.
**Spec:** Пользователь утвердил в текущей задаче выбор одного способа отображения на объект и проверку пяти файлов. Исходники DWG не изменять, производственные файлы не публиковать. Сохранение CAD-семантики стен не входит в задачу, визуальная геометрия и принадлежность слоям входят.

## Ограничения и риски

- Failsafe=false, нельзя скрывать исключения чтения; диагностические обходы остаются в private.
- Преобразования графики и блоков применяются ровно один раз; единицы и координаты Z сохраняются.
- Неизвестная команда графики должна давать явную ошибку/отчёт о неполноте, не считаться успешной.
- Повторная вставка блока допустима; двойное представление одной сущности недопустимо.
- Число сущностей не доказывает визуальную эквивалентность; проверять геометрию и сравнение кадров отдельно.

## Задачи

- [x] Конвертер: `tools/dwg-converter/ProxyConversion.cs`, модуль и синтетические тесты для линий, дуг, текста, полигонов, матриц, стилей, Shell; один блок на исходный объект, исходная сущность удаляется только после успешного построения замены.
- [x] Словари: сохранены обе записи STANDARD и их ссылки; прочие Error не игнорируются.
- [x] Интеграция: `Program.cs`, csproj/lock, версия движка в Rust и тестах; отчёт покрытия и отсутствия дублей, лицензии и документация.
- [x] Проверка: старый сбой воспроизведён; все пять исходников прошли нативный конвертер, Rust-импорт и построение кадра. Сверены хэши источников, состав, порядок и предупреждения. Синтетические тесты не требуют частных файлов.
- [x] Полный cargo test (225 passed), fmt, clippy и локальная сборка; независимое ревью. GitHub-публикация в этот запрос не входит.
- [ ] Полное совпадение с CAD остаётся неподтверждённым: отсутствует внешний PDF, не отображается одно 3DSOLID второго этажа, не реализованы листовые VIEWPORT и точные отсутствующие шрифты. Ограничения описаны в DWG_SUPPORT.md и предупреждениях приложения.

## Дополнения после проверки реальных файлов

- Нативное чтение, преобразование и повторная проверка состава/порядка прошли на всех пяти исходных DWG. SHA-256 источников не изменились.
- Реализованы WIPEOUT и порядок наложения; независимое ревью выявило и помогло исправить сопоставление безымянных DXF-записей и естественную сортировку по handle.
- Полный путь до кадра выявил схлопнувшиеся экранные вершины. Исправление сохраняет исходные данные, нормализуя только экранный путь; отдельный кадр вентиляции после исправления прошёл.
- Исправлены нулевые замкнутые двухточечные контуры HATCH; ограничения плотности остаются явными.
- Дополнительно восстанавливаются REGION из аналитических рёбер SAB. Перед завершением требуется новая нативная сборка и повтор всех пяти файлов с окончательным кодом.
- В лестнице есть внешняя PDF-подложка, отсутствующая рядом с DWG. Получить её изображение из одной ссылки невозможно. VIEWPORT и отсутствующие шрифты также не выдаются за полностью поддержанные.

## Итог проверки

Окончательный NativeAOT и все шесть C# проектов проверок прошли. Пять файлов повторно проверены через встроенный конвертер и построение кадра; восстановлены 812 REGION и 12 плотных HATCH. Сборка `dist/v0.9.9` подготовлена локально. В её настоящем окне открыт файл вентиляции, проверены загрузка, приближение и возврат к общему виду. Исходные DWG не менялись. Попиксельной сверки с авторской CAD нет; наличие перечисленных ограничений не скрывается.
