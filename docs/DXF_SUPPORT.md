# Просмотр DXF — версия 0.8.0

Приложение показывает двумерные ASCII DXF, включая чертежи, экспортированные из DWG, с геометрией, слоями, текстами и заливками. Для исходных DWG используется [встроенная конвертация](DWG_SUPPORT.md). Основной читатель `dxf` дополнен собственным разбором HATCH, ARC_DIMENSION и свойств слоёв: библиотека не возвращает эти сущности полностью. Ниже — фактическая поддержка текущей версии, а не обещание совместимости со всеми расширениями CAD.

## Проверенные типы

| Тип DXF | Отображение |
| --- | --- |
| LINE, ARC, CIRCLE, ELLIPSE, POINT | Геометрия с цветами и принадлежностью к слою |
| LWPOLYLINE, POLYLINE, SPLINE | Ломаные, дуговые сегменты и приближение кривых; исходные данные измерений сохранены |
| INSERT | Вложенные блоки, базовая точка, поворот, масштаб, отражение, массив вставок |
| TEXT, MTEXT | Текст, поворот, выравнивание, переносы, базовое встроенное форматирование и цвета |
| ATTRIB, ATTDEF | Значения атрибутов и видимые постоянные определения |
| DIMENSION, ARC_DIMENSION | Сохранённый графический блок размера: линии, стрелки, надписи |
| LEADER | Ломаная выноска и стрелка; связанная надпись загружается как отдельная сущность |
| SOLID, TRACE | Двумерная заливка |
| HATCH | Сплошная заливка, отверстия, вложенные островки; рисунок из линий/штрихов, обрезанный по границам |

Границы HATCH могут состоять из полилиний, прямых, дуг, эллиптических дуг и сплайнов. Криволинейные границы для заливки приближаются отрезками. Триангуляция — разбиение заливки на треугольники — выполняется библиотекой `earcutr` с лицензией ISC. Дополнительный внешний процесс или CAD SDK не требуется.

Слои: исходная видимость и заморозка, цвет, имя, наследование слоя 0 внутри блока, цвета BYLAYER/BYBLOCK, индивидуальный RGB, базовые линейные типы и вес линии. Скрытый родительский слой скрывает и содержимое вставки на других слоях. Заблокированные слои показаны, поскольку приложение не редактирует исходные сущности.

С версии 0.7.1 текстовый DXF читается с единым выбором кодировки по `$ACADVER` / `$DWGCODEPAGE` для основного и дополнительного обработчиков. Проверены Windows-1251 (включая `ansi_1251` строчными буквами), Windows-1252 и UTF-8 в DXF 2007+. Это сохраняет одинаковые имена у таблиц слоёв, ссылок объектов и блоков.

## Эталон и воспроизведение

Рабочий чертёж не публикуется. Проверка по переменной `DXF_REFERENCE_FIXTURE` рассчитана на согласованный эталон:

- Размер: 40 320 240 байт.
- SHA-256: `CDA06888C9A534AB41321C67F8297BB91DE7F30F3CB297EEF02846481276AD8B`.
- В исходных секциях модели и блоков: 566 HATCH, 7 ARC_DIMENSION, 210 DIMENSION, 337 MTEXT, 53 LEADER, 182 SOLID, а также базовая геометрия и вставки.
- После раскрытия блоков: 168 слоёв, 337 текстов, 735 заливок, более 110 тысяч геометрических элементов с учётом штриховки. Число примитивов после раскрытия отличается от числа исходных сущностей.
- Пропущено сущностей: 0; предупреждений импорта: 0. Это проверка покрытия типов, структуры и визуального результата, а не побайтовое сравнение с изображением из CAD.

```powershell
$env:DXF_REFERENCE_FIXTURE = 'C:\путь\к\эталонному.dxf'
cargo test --locked --release reference_drawing_has_no_missing_entities -- --ignored --nocapture
```

Без переменной частный тест пропускается. Общие тесты не требуют эталона и проверяют, среди прочего, отверстия в заливках, обрезку штриховки, поворот блока и текста, наследование слоёв и отсутствие привязок к скрытой геометрии.

## Границы поддержки

- Поддержка всех типов в этом эталоне не равна реализации всей спецификации DXF. Пользовательские объекты, изображения, подложки, 3D-тела и некоторые другие типы требуют отдельных обработчиков. Неподдерживаемые типы и ошибки восстановления показываются в карточке файла, а не скрываются.
- Расширенный разбор HATCH/ARC_DIMENSION предназначен для ASCII DXF. Для бинарного DXF выводится предупреждение об ограниченном импорте.
- Тексты рисуются встроенным шрифтом с кириллицей. Точное воспроизведение SHX/нестандартных шрифтов, сложных табуляций, наклона/ширины отдельных фрагментов MTEXT и многоуровневых дробей не заявляется; дроби показываются линейной записью. Возможны отличия от CAD в переносах и ширине надписей.
- DIMENSION должен содержать сохранённый графический блок. Пересчёт размеров по DIMSTYLE без блока не реализован. Выноски отображаются ломаной, без полной реализации всех вариантов оформления.
- Градиентные HATCH не поддерживаются. Слишком плотные штриховки и чрезмерная вложенность/повторяемость блоков ограничены с предупреждением, чтобы не создавать неограниченную геометрию.
- Толщина линий ограничена для читаемости; сложные типы линий со встроенными SHX-символами и переменная ширина полилиний не воспроизводятся точно. Очень мелкий текст и штриховые типы линий упрощаются при отдалении.
- Светлый фон намеренно сохранён. Белые линии становятся тёмными, остальные цвета сохраняются.
- Состояния слоёв действуют до закрытия окна; скрытие не меняет общий габарит исходного файла и уже поставленные пользователем размеры. Геометрия штриховок, текста и размерных обозначений не проверяется как контур для резки.
